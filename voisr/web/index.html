        Dictation

        Auto-paste in hotkey mode

        Paste straight into the app you're in, with Ctrl+V.

        How consecutive dictations join

        With screen context on, Voisr reads the text around your cursor and adds a space only after a word or sentence. Where it can't read the field, dictations in the same app within five minutes are joined with a space, unless you typed or clicked the mouse in between.

        Clipboard fallback

        Copied when auto-paste is off or blocked. After a successful auto-paste your previous clipboard is put back.

        Automatic

        Keep model loaded

        Keeps the next dictation from waiting on a model load. Holds about 0.7 GB for Small while loaded.

        More

        Voisr loads the model when you start talking and keeps it in memory, so the next dictation skips the model load. That saved roughly half a second to a second in tests, and varies. While it is loaded it uses about 0.7 GB of memory for Small and 0.3 GB for Base (more for bigger models), then frees it after the time you pick. “Immediately” reloads the model for every dictation and keeps no memory. Everything stays on this PC.

        Privacy & data

        Read the text around your cursor

        Spells names on screen correctly and checks your paste landed. Never reads password fields or password managers.

        More

        While you dictate, Voisr reads the app you are in: the field you are typing in, the window title and nearby labels. That spells names on screen correctly and checks that your paste landed. The text stays in memory for that dictation and is never saved. It never reads password fields or password managers. Off: Voisr reads no text from other apps.

        Learn from my corrections

        For up to a minute after a paste, re-reads that field to spot words you fixed. Only the corrected words are saved.

        More

        For up to a minute after a paste, Voisr re-reads that field to spot words you fixed, and suggests them in Dictionary. Only the corrected words are saved. Needs reading the text around your cursor.

        Add safe corrections automatically

        After the same fix twice, adds it if it only changes capitals or the spelling of one unusual word.

        More

        After you make the same fix twice, Voisr adds it to Dictionary without asking, if it only changes capitals or the spelling of one unusual word. Never common words or numbers. Everything else waits for you to accept it, and Dictionary marks what was added so you can remove it.

        Audio stays here

        Goes to a temp file, whisper.cpp transcribes it on this PC, then it's deleted. No accounts, no telemetry.

        Clear all history

        Permanently delete every stored dictation. This cannot be undone.

        Check for updates automatically

        Once a day, Voisr asks GitHub whether a newer version is out. That sends no audio, no text and nothing that identifies you. Updates download in the background, and nothing installs until you click Install.
