      Privacy & data

      Privacy

      Audio is recorded to a temp file, transcribed by whisper.cpp on this PC, then deleted. No accounts, no telemetry. The only network call is a version check to GitHub, which sends no audio, text, or identifying data.

      Local only

      Clear all history

      Permanently delete every stored dictation. This cannot be undone.

      Automatically check for updates

      Once a day, ask GitHub whether a newer Voisr has been released. Downloads happen in the background; nothing installs until you click Install.
